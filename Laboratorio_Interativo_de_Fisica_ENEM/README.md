# Laboratório Interativo de Física ENEM

## O que é este material?
Coleção de laboratórios interativos de Física para Ensino Médio, com foco em ENEM e vestibulares. Cada experimento está em um notebook próprio para Google Colab.

## Como abrir no Google Colab
1. Faça upload da pasta no Google Drive.
2. Abra um arquivo `.ipynb` com Google Colab.
3. Clique em **Ambiente de execução > Executar tudo**.

## Como executar os experimentos
- Rode todas as células.
- Ajuste os controles (sliders, seletores).
- Observe os gráficos e a interpretação física.
- Resolva os exercícios e confira o gabarito.

## Como estudar com este material
- Siga a ordem sugerida no `00_Indice_Geral.ipynb`.
- Faça anotações das relações entre fórmulas e gráficos.
- Refaça os exercícios sem consultar o gabarito inicialmente.
- Use o desafio extra para aprofundar entendimento.
