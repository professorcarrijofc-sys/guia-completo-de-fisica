# Laboratório Interativo de Física - ENEM

Projeto didático com simuladores interativos de Física para **Ensino Médio, ENEM e vestibulares**.  
Todos os materiais foram organizados em notebooks independentes para uso direto no **Google Colab**, sem instalação local.

## Como usar (alunos)
1. Clique no notebook desejado.
2. No Google Colab, clique em **Ambiente de execução > Executar tudo**.
3. Leia a teoria, acompanhe os exemplos e teste os simuladores com os controles interativos.

> ✅ Dica importante: sempre execute tudo antes de mexer nos sliders.
