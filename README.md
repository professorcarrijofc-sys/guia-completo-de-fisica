# Laboratório Interativo de Física - ENEM

Projeto didático e comercial com **20 notebooks interativos reais** para alunos do Ensino Médio, ENEM e vestibulares.
Você **não precisa instalar nada**: basta abrir no Google Colab e clicar em **Executar tudo**.

## Como usar
1. Clique em um link abaixo.
2. No Colab, clique em **Ambiente de execução > Executar tudo**.
3. Interaja com sliders e observe os gráficos.
4. Resolva os exercícios e confira o gabarito.
