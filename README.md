# 🚀 Física Interativa com Python

**Guias completos de Física com animações, sliders interativos, gráficos em tempo real e cálculos automáticos.**

Tudo roda direto no **Google Colab** — zero instalação!  
Perfeito para alunos do **Ensino Médio, Enem, Vestibular** e professores que querem transformar a aula em uma experiência visual e prática.

---

### 📖 Como usar
1. Escolha o tópico abaixo  
2. Clique no link do notebook desejado  
3. No Google Colab clique em **Runtime → Run all** (ou Ctrl + F9)  
4. Divirta-se mexendo nos sliders e assistindo as animações!
